# Deferred UI

These files were built early during L0 and have been moved outside `app/` so that we strictly follow the layer plan (building backend first, UI later in L6).

To be reviewed when UI work starts, using the `apple-design`, `design-taste-frontend`, and `frontend-design` skills.

### Contents:
- `page.landing.js`: Landing page with hero, 3 steps, 6 scam types, and CTA.
- `page.check.js`: Check submission form with input and consent checkbox.
- `page.check-id.js`: Dynamic check status inspection view.
- `layout.js`: Header with brand shield navigation and disclaimer footer.
- `globals.css`: Full design tokens, light/dark mode variables, translucent glass materials, button and card styles.
